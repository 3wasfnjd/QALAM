# القلم — QALAM

لعبة ألغاز ومغامرة بالواقع المختلط على Meta Quest 3 / 3S من **عبودين قيمز / ABODEN GAMES**. Godot 4.7 + OpenXR + Passthrough، بناء APK عبر GitHub Actions.

**آخر قلم في العالم.** دفتر رسم ينفتح على طاولتك ويطلع منه عالم ورقي باهت. أنت تحرّك القلم، وبيدك **ترسم** الجسور فتصير حقيقية، وكل لغز تحله يعيد الألوان للعالم.

> هذه نسخة لتجربة **طريقة اللعب والفكرة** فقط (صفحة واحدة). الشخصية والعالم أشكال بسيطة مؤقتة؛ الموديلات الحقيقية مرحلة قادمة.

## التحكم
- **وضع الدفتر**: الدفتر المغلق يتبع نظرك؛ العصا ↑↓ ترفع/تنزل الطاولة؛ الزناد أو A/X يضعه. ضغطة العصا (أثناء اللعب) ترفع الدفتر لتضعه في مكان آخر.
- **حرّك القلم**: العصا (أي يد) — الاتجاه بالنسبة لنظرك.
- **اقفز**: A أو X.
- **ارسم**: اضغط الزناد وارسم بطرف القلم الذي في يدك. الخط يصير **جسرًا خشبيًا** إذا بدأ وانتهى على سطحين (تظهر دائرة خضراء على السطح حين يكون طرف قلمك قريبًا منه). غير ذلك يتفتت ويسقط.
- **امسح آخر جسر**: B أو Y (يرجع الحبر).
- **الحبر**: طول القلم في يدك يقصر كلما رسمت.
- **ادفع الكرة الورقية** بالقلم الصغير، أو انفضها بيدك.

## الصفحة الأولى
1. البداية على جرف باهت فيه شجرة يابسة ولافتة «ما زال .. هناك أمل»، وفجوة لا تُقفز (خط منقّط يلمّح للرسم).
2. ارسم جسرًا واعبر.
3. ادفع الكرة ذات النجمة إلى اللوح ذي النجمة → تتلوّن المنطقة وتعود البوابة المكسورة وتنفتح.
4. اقفز إلى الجرف العالي (أو ارسم منحدرًا) واصل إلى النجمة → يعود اللون للعالم كله، تنبت الشجرة والزهور، ويحتفل القلم. A يعيد الصفحة.

السقوط على الورقة البيضاء يعيد القلم (أو الكرة) إلى آخر نقطة.

## الفصل بين الحالات
دائمًا: **تم البناء** / **تم فحص الحزمة** / **نجحت الاختبارات الآلية** / **تم التثبيت على Quest بواسطة صاحب المشروع** / **تم اختبار اللعب بواسطته**. صور `build/previews/` معاينة مكتبية على خلفية رمادية اصطناعية، ليست من النظارة.
